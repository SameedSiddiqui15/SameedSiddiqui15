AI can write code. My job is to find the real cause of a problem, decide what to build, and prove the fix works before it ships.

I build web applications end to end: the frontend, the API, the database and the integrations in between. Most of my professional work lives in private repositories, so the public repos below are mostly learning and course projects.

## What I work on

- **Web apps:** Next.js (App Router, server components), React + Vite, TypeScript, Tailwind CSS, Angular
- **Backend:** Node.js / Express, Python (Flask, Django), REST APIs with OpenAPI and Zod
- **Databases:** PostgreSQL with Drizzle ORM and SQLAlchemy, schema migrations
- **Integrations:** webhooks, email (Mailchimp), SMS and calling (Twilio), PDF generation, calendar sync
- **AI features:** LLM-drafted content that waits for human approval, with guardrails, escalation rules and a circuit breaker
- **Tracking and SEO:** Google Analytics 4, Google Tag Manager, conversion tracking, structured data (JSON-LD), sitemaps, content that search engines and AI answer engines can cite
- **Delivery:** Git, GitHub Actions, Docker, automated tests (Vitest), FFmpeg media pipelines, written documentation

## How I work

- I reproduce a bug before I fix it, and I check the fix in the running app, not only in the code.
- I write down why a decision was made, so the next person doesn't have to guess.
- I use Claude Code every day as a pair programmer and review every change before it ships.
